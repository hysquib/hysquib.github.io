存储模式

选择博客文章的存储方式。"GitHub" 模式直接发布到你的仓库（需要 Personal Access Token）。"本地" 模式仅在浏览器中保存文章。

GitHub Personal Access Token

"GitHub" 存储模式必需。请前往 github.com/settings/tokens 创建一个具有 repo 权限的令牌。令牌仅保存在当前浏览器会话中（关闭标签页即清除）。

修改管理密码

如需修改管理密码，请编辑 js/config.js 并更新 PASSWORD_HASH 值。

在终端运行以下命令生成新哈希：

echo -n "你的新密码" | sha256sum

然后将输出的哈希粘贴到配置文件中并提交到 GitHub。
