Settings

Storage Mode

"GitHub" mode publishes directly to your repository via the Worker (requires GitHub login). "Local" mode stores posts in your browser only — useful for drafting.

Currently using: GitHub

Authentication

Admin access is secured via GitHub OAuth. Only the authorized GitHub account can login. No passwords are stored in the frontend.

To change the authorized user, update the ALLOWED_USER environment variable in your Cloudflare Worker.
