存储模式

"GitHub" 模式通过 Worker 直接发布到你的仓库（需要 GitHub 登录）。"本地" 模式仅将文章存储在浏览器中 — 适合草稿编写。

当前使用：GitHub

认证

管理后台通过 GitHub OAuth 进行安全认证。只有授权的 GitHub 账号可以登录。前端不存储任何密码。

如需更改授权用户，请更新 Cloudflare Worker 中的 ALLOWED_USER 环境变量。
