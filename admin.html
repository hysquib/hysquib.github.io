Storage Mode

Choose how blog posts are stored. "GitHub" mode publishes directly to your repository (requires a Personal Access Token). "Local" mode stores posts in your browser only.

Currently using: local

GitHub Personal Access Token

Required for "GitHub" storage mode. Create a token at github.com/settings/tokens with the repo scope. The token is stored only in this browser session (cleared when you close the tab).

Change Admin Password

To change the admin password, edit js/config.js and update the PASSWORD_HASH value.

Generate a new hash by running this in your terminal:

echo -n "your_new_password" | sha256sum

Then paste the output hash into the config file and commit to GitHub.
